Project: Building a Simple Chatbot

Below is a basic implementation of a chatbot using Python:

```python
import random

responses = {
    "hello": ["Hi there!", "Hello!", "Greetings!"],
    "how are you?": ["I'm a computer program, so I don't have feelings, but thanks for asking!", "Doing well, how about you?"],
    "bye": ["Goodbye!", "See you later!"]
}

def chatbot_response(user_input):
    for key in responses.keys():
        if key in user_input.lower():
            return random.choice(responses[key])
    return "I'm sorry, I don't understand."

# Sample interaction
user_input = input("You: ")
print("Chatbot:", chatbot_response(user_input))
```

This project demonstrates how to create a basic chatbot that can interact with users, illustrating the practical skills acquired during the course.
